
  # 🚀 Telkom-In-Competition

Telkom-In-Competition merupakan platform kompetisi mahasiswa berbasis web yang dirancang untuk membantu mahasiswa menemukan, mengikuti, dan mengelola berbagai kompetisi akademik maupun non-akademik secara lebih mudah, modern, dan terstruktur.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
